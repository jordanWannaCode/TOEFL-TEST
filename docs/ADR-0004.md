# ADR 0004 — Writing et évaluation différée
Statut : adopté.

Réutiliser `exam_sessions`, `session_items`, `responses`, révisions, reçus idempotents, propriétaire authentifié et échéance serveur. Les réponses Writing sont `{elementIds:[...]}` ou `{text:"..."}`. Build a Sentence utilise des variantes privées exactes ; aucun LLM intervient. Les réponses libres sont clôturées avant tout job IA.

La file PostgreSQL `evaluation_jobs` évite Redis. Le worker Spring réclame un job avec `FOR UPDATE SKIP LOCKED`, libère la transaction avant l'appel HTTP, puis confirme avec un bail. Timeout HTTP 45 s, bail 65 s, trois essais automatiques avec délai ; récupération des baux expirés et relance explicite des échecs. Une contrainte unique par item empêche les doubles jobs/résultats. Un crash après facturation fournisseur peut toutefois provoquer un second appel : l'idempotence locale ne garantit pas l'idempotence commerciale distante.

FastAPI possède les adaptateurs OpenAI et Anthropic derrière `EvaluationProvider`, le prompt versionné et le schéma Pydantic strict. Spring garde la persistance, les permissions et les règles. L'appel est unidirectionnel ; FastAPI ne rappelle pas Spring et n'est pas une seconde base de jobs. Authentification interne par secret partagé généré localement, HTTPS à imposer entre hôtes en déploiement. Endpoints fournisseurs HTTPS fixes, aucun endpoint arbitraire.

Les rubrics versionnés stockent des dimensions pédagogiques locales, poids égaux et échelle 0–5. Le total est calculé par le validateur, jamais repris aveuglément du modèle. Aucune conversion ETS/CEFR officielle. Citations et erreurs doivent correspondre à des spans exacts de la réponse ; cela contrôle l'ancrage textuel, pas la justesse linguistique. Les incertitudes sont affichées.

L'absence de fournisseur produit UNAVAILABLE et conserve les réponses. Le fournisseur déterministe exige simultanément `WRITING_AI_PROVIDER=test` et `APP_ENV=test`. Il n'est activé que dans le projet Compose E2E et dans les tests. Pas d'évaluation fictive en fonctionnement normal.
