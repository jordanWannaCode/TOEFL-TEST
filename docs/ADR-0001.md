# ADR 0001 — Architecture initiale
Statut : accepté pour Sprint 0. Date : 13 octobre 2026.
## Contexte
Un premier étudiant, avec perspective SaaS ; privilégier cohérence transactionnelle et capacité à faire évoluer les règles.
## Décisions
Angular 20 (LTS), TypeScript, Material et Tailwind pour une interface accessible. Spring Boot 3.5 / Java 21, monolithe modulaire, possède transactions, autorisations, timing et correction objective. FastAPI est un service séparé pour les futures évaluations IA, sans accès direct aux tables métier. PostgreSQL est la source de vérité ; Flyway versionne le schéma. MinIO conserve les futurs médias. Docker Compose constitue l'environnement local ; pas de Redis ni worker tant que la charge asynchrone ne l'exige pas.
Modules prévus : identity, content, blueprint, examination, scoring, evaluation, analytics. Sprint 0 ne crée pas artificiellement leurs implémentations. Les futurs modules exposent des interfaces et des événements métier ; les cycles sont interdits.
Blueprint publié immuable, session liée à une version et à un instantané. Horloge UTC serveur et deadline persistée ; un compteur frontend est indicatif. Réponses enregistrées indépendamment de la clôture ; version optimiste et clés d'idempotence rendent les retries explicites.
Identité Sprint 1 : session serveur avec cookie HttpOnly, CSRF et provisionnement personnel hors Git ; principal serveur avec owner UUID sur les agrégats privés, autorisation à chaque lecture/écriture ; auth commerciale à choisir. Sprint 0 n'expose que la santé et ne constitue pas une application sécurisée pour Internet.
IA : contrat indépendant du fournisseur avec version du modèle/rubric et statut d'échec ; score estimé. À terme, outbox transactionnelle et workers si les latences dépassent le budget HTTP.
## Conséquences et alternatives
Les microservices métier multiplieraient déploiements et transactions distribuées sans bénéfice initial. Le monolithe exige discipline des frontières et tests d'architecture à introduire avec les modules. L'IA séparée ajoute un contrat réseau mais évite de coupler Python et Java. Les sessions résilientes exigent persistance et tests de concurrence en Sprint 1.
Santé : liveness du processus distincte de readiness dépendante de PostgreSQL. L'absence de clé IA ne bloque pas Sprint 0 ; aucune estimation n'est simulée.

MinIO construit depuis les sources officielles figées en raison de refus des images testées ; SHA-256 de l’archive fixé, licence amont conservée. Les images et outils sont versionnés ; leur mise à jour de sécurité reste un entretien explicite.
